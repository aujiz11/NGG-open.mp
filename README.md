## 📋 Overview

**Next Generation Gaming** là một trong những gamemode roleplay phổ biến nhất tại Việt Nam, được tin dùng bởi cộng đồng SA-MP trong nhiều năm qua. Với mục tiêu nâng cấp và hiện đại hóa, mình đã phát triển lại hoàn toàn NGG trên nền tảng open.mp với nhiều cải tiến mới.

### ✨ Tính năng nổi bật

- 🔄 Được viết lại hoàn toàn với các thư viện hiện đại
- ⚡ Tối ưu hiệu suất và fix nhiều lỗi từ phiên bản cũ

## 🔧 Required Plugins

| Plugin | Version | Description |
|--------|---------|-------------|
| [Streamer](https://github.com/samp-incognito/samp-streamer-plugin/releases/tag/v2.9.5) | v2.9.5 | Object & pickup streaming |
| [MySQL](https://github.com/pBlueG/SA-MP-MySQL/releases/tag/R33) | R33 | Database connectivity |
| [Whirlpool](https://github.com/Southclaws/samp-whirlpool/releases) | Latest | Password hashing |
| [sscanf](https://github.com/Y-Less/sscanf/releases/tag/v2.13.8) | v2.13.8 | String parsing |
| [I-ZCMD](https://github.com/YashasSamaga/I-ZCMD) | Latest | Command processor |

## 🚀 Quick Start

1. Download phiên bản mới nhất `(git clone https://github.com/aujiz11/NGG-open.mp.git)`
2. Đảm bảo các thư viện như trên đã có
3. Cấu hình file `config.json` phù hợp với bạn
4. Cấu hình database bên trong `scriptfiles/mysql.cfg`
5. Mở omp-server.exe
